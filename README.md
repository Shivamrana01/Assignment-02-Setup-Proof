# HTML & CSS Practical Assignments

This repository contains my practical assignments for learning HTML, CSS, Git, and GitHub as part of my web development journey.

## 📚 About the Project

The project includes 45 practical assignments divided into 9 modules, covering HTML fundamentals, CSS styling, layouts, and responsive web design.

## 🗂️ Assignment Modules

1. **Setup & Git** — Development tools, terminal navigation, and GitHub.
2. **HTML Basics** — Headings, text elements, and semantic HTML.
3. **Links, Images & Lists** — Navigation, images, and lists.
4. **Forms, Tables & Metadata** — Forms, tables, and metadata.
5. **CSS Fundamentals** — Selectors, typography, colours, and CSS variables.
6. **Box Model & Positioning** — Spacing, cards, and positioning.
7. **Flexbox** — Flexible and responsive layouts.
8. **CSS Grid** — Galleries, product grids, and dashboards.
9. **Responsive Design & Integration** — Breakpoints and responsive landing pages.
